# 中控屏自动接管配置

网关密钥、网关身份和配件清单由桥接程序在中控屏本机读取，不要求人工输入，也不会传回安装电脑。门锁 Wi-Fi 在线传感器是可选项，按每户手动配置，数据只存在该户的中控屏上。

| 运行参数 | 来源 | 当前核验结果 |
| --- | --- | --- |
| AES 密钥 | `cn.net.cloudthink.smartmirror` 的 `app_gatewaysdk/config.db`，字段 `ihgAeskey` | 32 位十六进制，即 16 字节 AES-128 密钥；和当前桥密钥一致。协议使用 AES-128-CBC。程序不打印密钥、不经 ADB 传到安装电脑。 |
| 网关 MAC | 同一 `config.db` 的 `ihgMac` | 与当前桥身份一致。 |
| 网关 IP | `/proc/net/arp` 中 MAC 对应的邻居地址 | 当前屏能解析到网关。配置文件里没有持久化 IP；如果邻居表还没有记录，部署前打开厂商 App 并等它连上网关即可，安装器会先检查并提示。 |
| 网关 UDP 端口 | IHG2 屏端协议常量 | 当前中控屏实测为 `80`。 |
| 协议设备 ID / 类型 | IHG2 屏端协议常量 | 当前屏端传入设备 ID `1`，实测报文类型为 `0x274a`。这两项是当前屏型号/固件的协议参数，不是每户独立配置。 |
| 配件清单、名称、平台、通道和属性 | SDK 的 `subdevs.db` 及其中的 `vgroups` | 从 48 条屏端设备记录自动生成 31 条桥接配件；与当前桥的 31 条库存逐条完全一致。目录由厂商 App 同步维护。 |
| HomeKit 名称和端口 | 桥的默认值 | 自动使用 `IHG2 Local Bridge` 和 TCP `53760`；不需要从网关读取。 |
| 门锁 Wi-Fi 在线传感器 | 每户维护电脑手动写入屏端 `config/lock-sensor.conf` | 写入该户门锁 IP 和 Wi-Fi MAC；只对这个 IP 发 ARP 探测并校验 MAC，不扫描网段。运行中重读，不需要编译。它表示局域网可达，不等同于门锁已解锁。 |
| HomeKit 配对身份 | 屏端 `.hap_store` | 首次自动生成并保存在屏上；更新部署保留已有配对。安装后仍需在 Apple 家庭中完成一次“添加配件”。 |

`config.db` 和 `subdevs.db` 是 Android 应用私有文件，当前文件权限为应用 UID 的 `0600`。桥以 root 运行，因此能只读访问。自动接管不改写厂商数据库，也不导出 App 云令牌、授权字段或场景数据。网关 AES 密钥保存在中控屏 SDK，而不是通过网关接口取回；不应把网关当作密钥分发服务。

自动接管只适用于已验证的 RK3288/Android 固件、root、相同厂商 App 包名和 SDK 文件布局。目前实机核验样本是一台中控屏，因此其他业主家的屏仍需先运行 `--doctor` 确认兼容；不能仅凭“版本差不多”就当作验证完成。超过桥的 32 个配件上限，或厂商更改数据库结构时，程序会拒绝启动并由 `--doctor` 报告，不能静默生成半套配件。设备分类规则来自 SDK 的逻辑通道类别和属性；未知类别需要更新程序后重新编译一次，再把同一新版发布包部署给所有匹配的屏，不需要按家庭编译。

代码和硬件运行环境匹配时，每个软件版本只需构建、打包一次；每户的 AES 密钥、网关 IP 和配件目录都在运行时从该户中控屏读取，不会编译进程序或打包进发布文件。若需要门锁 Wi-Fi 在线传感器，每户再通过 `install.sh PANEL_IP --configure-lock LOCK_IP LOCK_MAC`（Windows: `install.cmd PANEL_IP -ConfigureLock -LockIp LOCK_IP -LockMac LOCK_MAC`）写入本地私有配置；维护电脑通过 ADB 调用屏上程序完成，无需重新编译。

发布包放在 Windows 或 Linux 维护电脑，由电脑通过 ADB 部署或检查。首次使用前仍须在中控屏启用 ADB 调试并授权该电脑。电脑端检查命令是 `install.sh PANEL_IP --doctor`（Linux）或 `install.cmd PANEL_IP -Doctor`（Windows），屏端命令是以 root 运行 `ihg2-arm-bridge --doctor`。Doctor 不显示网关密钥、MAC、IP、设备名称或设备标识；所有健康检查通过后，会显示用于首次添加到 Apple 家庭的 HomeKit 配对码（若受保护的配对码文件存在且格式有效）。它会发送一个只用于连通性检查的网关心跳，不发送开关、窗帘或空调控制命令。
