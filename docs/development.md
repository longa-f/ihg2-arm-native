# 开发与发布说明

本文只供维护 IHG2 ARM 本地桥源码和构建发布包的开发人员使用。它不随面向家庭安装的发布包提供；日常安装请看 README.md。

## 项目范围

本项目是运行在 RK3288 同类中控屏上的独立 ARMv7 服务。一个原生进程负责网关 UDP 通信、固定容量的设备状态表、命令队列、HomeKit 桥和可选的门锁在线监测。运行时不依赖 Home Assistant、Homebridge、MQTT、Node.js、开发服务器或云端会话，也不支持场景增删改。

配件按网关清单映射到 HomeKit：

- 灯具使用灯泡服务；网关提供相应属性时同时提供亮度和色温。
- 窗帘使用窗帘服务，暴露当前位置、目标位置和运动状态；网关位置值以百分比表示。
- 空调使用恒温器服务，提供当前温度、目标温度、电源和模式控制。当前模式枚举暂按 0 自动、1 制冷、2 除湿、3 送风、4 制热映射；尚未通过设备现场逐一确认。HomeKit 没有除湿和送风目标模式。
- 雷达或人体移动传感器使用占用传感器服务；水浸传感器使用漏水传感器服务。两者为只读状态，由网关报告驱动。
- 可控制但没有专用类型映射的项目使用开关服务。配置后的门锁 Wi-Fi 在线状态使用占用传感器服务；它表示本地网络可达，不表示已解锁。

色温使用 HomeKit mirek 值表示，并映射到网关 0–100 的 colortemp 字段。现场确认主卧灯带数值 0 对应最暖，因此网关数值从 0 到 100 表示由暖到冷。中间值采用线性换算；目前只有最暖端点经过现场确认。

## 协议和安全边界

网关数据包采用 AES-128-CBC 和累加校验，协议本身没有加密认证标签。程序在修改设备状态前检查报文长度、校验和、网关身份、消息类型和解密后的 JSON。HomeKit 配对会话由 HAP 引擎提供密码学保护。网关密钥和 HomeKit 配对数据留在中控屏，不写入发布包。

HomeKit 实现使用固定版本的 Apple HomeKit ADK。ARM 程序静态链接 OpenSSL 3.5.9 和 C++ 运行库；屏端唯一外部动态库依赖是固件自带的 /system/lib/libmdnssd.so。

## 版本与测试

VERSION 是软件版本号的唯一来源，采用 MAJOR.MINOR.PATCH：

- 兼容性 bug 修复增加 PATCH。
- 向后兼容的新功能增加 MINOR。
- 不兼容改动增加 MAJOR。

每个发布版本都要更新 VERSION，并确保二进制中嵌入的版本号与它一致。发布包使用带版本号的文件名，并生成 SHA-256 校验文件。打包脚本默认拒绝覆盖同版本归档；只有有意在本地重打包时才使用 scripts/package-android.sh --force。

运行主机测试：

    make clean test

测试需要 C++20 编译器和 OpenSSL 开发库；nlohmann/json 3.11.3 已包含在 third_party 中。测试覆盖状态存储、网关协议向量、UDP 循环、HomeKit 窗帘/色温/恒温器映射、屏端配置、日志轮换、门锁在线状态、部署日志和失败回滚。

## 构建和打包

ARM 构建使用 Android NDK r30、OpenSSL 3.5.9 源码，以及匹配目标面板固件的 libmdnssd.so。先初始化固定版本的 HomeKit ADK 子模块。构建脚本会在临时覆盖目录应用短 nonce 兼容补丁，不修改上游子模块内容。

设置工具链路径后构建并打包：

    ANDROID_NDK_HOME=/path/to/android-ndk-r30 \
    OPENSSL_SOURCE=/path/to/openssl-3.5.9 \
    MDNS_LIBRARY=/path/to/panel-libmdnssd.so \
    make package-android

该目标会先编译 Android ARMv7 程序，再创建发布归档。产物目标为 Android API 25、32 位 armeabi-v7a；OpenSSL 和 C++ 运行库静态链接。

在维护电脑上也可以使用已有的工具链脚本：

    ~/3rd/build-ihg2-arm-native.sh

该脚本设置本机工具链位置并执行同一构建和打包流程。应针对每个软件版本和硬件配置构建一次，再把同一发布包用于所有兼容家庭。每户的网关密钥、网关地址和配件清单均在屏端运行时读取，不需要按家庭重新编译。

发布前检查 VERSION 与二进制版本一致，运行 make clean test，确认打包生成的 SHA-256 文件有效，并将源码改动提交。正式发布可在对应提交上创建匹配版本的 Git 标签，例如 v1.2.1。
